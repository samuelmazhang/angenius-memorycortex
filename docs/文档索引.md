## 文档维护原则

1. **职责分离**: 总览（是什么）vs 设计（怎么做）vs 路线图（已做什么 + 未来）
2. **避免重复**: 内容变化时优先更新已有文档
3. **决策追溯**: 重要架构决策（删除/重构）保留在 V4.x路线图的附录
4. **代码同步**: API 端点变更 → 同步更新 架构总览.md 的 API 表格
5. **版本对齐**: 每个新版本完成后，更新 V4.x路线图的"当前状态"表
