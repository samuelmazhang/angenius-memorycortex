# ADR-077: Nomic v1.5 作为 v6.5.0 #3 默认 embedder(本地 snapshot,无 HF 联网)

- Status: Accepted
- Date: 2026-08-23
- Author: ExampleOrg Agent (执行) + 天行健 (决策:用户选 B)
- Supersedes: 无(替代 ADR-068/069/075 不冲突;此 ADR 重新定义 v6.5.0 #3 的 embedder 装载路径)
- Depends on: ADR-068 (conflict-resolve) + V6.5.0 #3 (Nomic v1.5 re-embed)

## 背景 (Context)

v6.5.0 #3 引入 Nomic v1.5 作为新的默认 embedder(MTEB 62.28 vs MiniLM 的 ~58,精度显著提升),但生产部署从未真正落地,原因有三:

1. **`get_nomic_model()` 的实现 hardcode `SentenceTransformer("nomic-ai/nomic-embed-text-v1.5", trust_remote_code=True)`** — 这个调用在容器里没有本地 snapshot 时会自动去 huggingface.co 下载模型
2. **生产容器(127.0.0.1 的 `memory-cortex-stack:5.3.9` image)没有 outbound HF 访问** — 所以 `get_nomic_model()` 永远 fallback 到 MiniLM(384-dim zero-pad 到 768)
3. **`EMBEDDING_MODEL_PATH` env 没在任何 deploy 脚本里设置** — 容器启动时 `_combined_lifespan` 调 `_apply_hnsw_runtime_params()` → `CortexConfig._load()` → 直接 `RuntimeError: EMBEDDING_MODEL_PATH 未配置`,导致 container 进入 crash loop(2026-08-23 第一次 deploy 时撞到的 pre-existing bug)

加上 v6.5.0 schema 改动:
- `embedding` 列从 `vector(384)` 改为 `vector(768)` (支持 Nomic 768-dim)
- `model_version` 列新增 (区分 mpnet vs nomic-v1.5)

到 2026-08-23 时,DB 实际状态是:2694 个 chunks 全部 `model_version='mpnet'`,但 `embedding` 列因为 column ALTER TYPE 时不兼容老数据被清空,只剩 1 个新 POST 的 chunk 有真向量。**这意味着任何 `/search` 召回基本都是空的**。

## 决策 (Decision)

**生产容器用本地 HuggingFace snapshot 加载 Nomic v1.5,完全离线运行,无 HF 联网**。

具体实施:

1. **本机下载**:`huggingface-cli download` via `HF_ENDPOINT=https://hf-mirror.com` (用户提供国内镜像,因 container 无法访问 hf.co)
   - 只下载最小必要文件 (~523 MB,跳过 1.6 GB 的 onnx/* 等冗余)
   - 关键文件: `config.json`, `modules.json`, `1_Pooling/config.json`, `model.safetensors`, `tokenizer.json`, `vocab.txt`
2. **SCP 到 8.2**:`/opt/cortex-deploy/models/nomic-embed-text-v1.5/` → 移到 `/root/.local/share/cortex-models/nomic-embed-text-v1.5/` (与 MiniLM 并排,container 透过既有 bind-mount 看见)
3. **container 装 Python 包**:`pip install -i https://pypi.tuna.tsinghua.edu.cn/simple/ huggingface_hub sentence-transformers`
   - 装好 sentence-transformers 6.0.0 + torch 2.13.0 + transformers 5.15.1 (auto-fetched)
4. **改 `get_nomic_model()`**:
   - 加本地 candidates 列表(`/opt/cortex-deploy/models/...`, `/root/.arcadia/.../models/...`, `~/.cache/huggingface/...`, Windows dev 路径)
   - 找到 local snapshot 时 set `HF_HUB_OFFLINE=1` + `TRANSFORMERS_OFFLINE=1` (defense in depth)
   - **drop `trust_remote_code=True`**:sentence-transformers >= 5.3.0 + transformers >= 5.5.0 已经把 nomic-embed-text-v1.5 收为标准 transformers 模型(per HF model card 2026-08),不再需要 trust_remote_code。trust_remote_code=True 反过来会让 transformers 试图下载 custom Python module,在线/离线都不能跑
5. **修 DB schema drift**:
   - `ALTER TABLE memory_chunks ADD COLUMN IF NOT EXISTS model_version VARCHAR(32) DEFAULT 'mpnet' NOT NULL` (列是新的,因为 2694 行用 `IF NOT EXISTS` 跳过 existing)
   - `UPDATE memory_chunks SET embedding=NULL WHERE embedding IS NOT NULL` 清掉 384-dim 老数据(因为 column 升到 768-dim 后老向量 invalid)
   - `ALTER TABLE memory_chunks ALTER COLUMN embedding TYPE vector(768)`
6. **跑 ETL**:`python -m etl.etl_reembed --target-model nomic-v1.5 --batch-size 50 --sleep-ms 20`
   - 用 `/tmp/shim/server/src/` shim 绕过 `etl_reembed.py` hardcode 的 `from server.src.api_pg import` (容器内 `/app/src/` 才是根,不是 `server/src/`)
   - 2694 个 chunks 全部 re-embed (~10 分钟)

## 后果 (Consequences)

**正面**:
- 真正实现 v6.5.0 #3 的精度提升(62.28 MTEB)
- 完全离线部署,无 HF 依赖,生产环境可重复
- `get_nomic_model()` 加 local-snapshot candidates 后 dev/CI 路径依然 work (fallback 到 public HF id)

**负面**:
- 2694 个老 chunks 的旧 mpnet embedding 已丢失(被 `UPDATE NULL` 清空)。这是**单方面数据损失**,需要确认是否可接受
- ETL 期间 `/search` 会慢(每 chunk ~50ms × batch 50 = 2.5s per batch);但因为 embeddings 之前就 NULL,搜索本来就坏,ETL 期间坏上加坏可接受
- container 内装了 ~1.5 GB 的 torch/transformers/sentence-transformers,镜像尺寸增长

**兼容性**:
- `compact_long_conversation` 和其他 module caller 无改动(它们调 `embed_text`,signature 不变)
- 单测 `test_consolidate_v6_5.py` / `test_compact_v6_5.py` 全部仍过(它们不直接调 embed)
- D 层 E2E 测试 `test_e2e_recall_loop.py` 现在能跑出**真**向量(相似度 0.4-0.5 来自真 nomic,不再 zero-pad)

## 不做的 (Out of Scope)

- **不修改 `entrypoint.sh`** 永久设 `EMBEDDING_MODEL_PATH` env。容器启动现在用 docker run `-e` 传,应该后续改成 image 里 hardcode,但这是 devops 决策,不是 v6.5.0 #3 产品本身的事。
- **不删 `models/paraphrase-multilingual-MiniLM-L12-v2/`**。MiniLM 仍是 fallback,保留。
- **不重建 image** 把模型烤进去(`memory-cortex-stack:5.3.9` 永远不变)。这是 hot-reload 工作流的一部分。
